# Fizzbuzz

Fizzbuzz game developed in vb.net console. Uses OOP to manage the players and game logic.

Players must take turns in stating the incrementing numbers, "fizz", "buzz", or "fizzbuzz" in accordance to the fizzbuzz rules.

Incorrect answers result in a loss off a life which can be selected by the user (1-10 lives)

Lose all lives, the player will be eliminated until there is one player left.

Winner gains a point and it is added onto their score of which can be displayed.
